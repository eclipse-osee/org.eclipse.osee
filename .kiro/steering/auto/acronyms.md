# Chat Acronyms

Shorthand the user may use when talking to the AI. Expand and act on them.

| Acronym | Meaning | Behavior |
|---------|---------|----------|
| SF | Steering file(s) | Refers to files under `.kiro/steering/`. |
| AT | After that | Not an interruption. Finish the current task, then do this as the next step. |
| KC | Keep concise | Keep the response/output short and to the point. |
| SP | Store progress | Record current progress in the appropriate steering/progress file so a future session can resume. |
